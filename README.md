# Gearbook

Every new car on sale in India: 302 models from 43 brands, with on-road prices for 44 cities, colours, full specifications, features, owner reviews, search and compare.

Live site: https://tarun-maripat.github.io/gearbook/

- Prices, specifications and owner-review excerpts: CarDekho, November 2026.
- Car photos: Wikimedia Commons and Flickr (via Openverse), each credited on the car's page with its licence.
- Brand logos: Wikimedia Commons. Logos are trademarks of their owners.

Static site: open `index.html`, or serve the folder with any web server.
